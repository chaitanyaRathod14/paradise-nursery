# Paradise Nursery

Paradise Nursery is an online plant shopping application for discovering and buying beautiful houseplants.

## Purpose

The app gives plant lovers a simple way to browse plants by category, add favorites to a cart, adjust quantities, and review an order total.

## Main features

- Landing page with nursery-inspired imagery and navigation
- Indoor, succulent, and flowering plant categories
- 18 unique plants with photos, descriptions, and prices
- Redux Toolkit shopping cart with duplicate prevention
- Quantity controls, remove actions, dynamic item count, and totals
- Responsive layout for desktop and mobile screens
- Checkout placeholder with a “Coming Soon” message

## Technologies

- React
- Vite
- React Router
- Redux Toolkit and React Redux
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually `http://localhost:5173`.

To create a production build:

```bash
npm run build
```
